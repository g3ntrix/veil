# Changelog

## 0.1.0

First version.

- Setup wizard from "I have a VPS" to a working, tested connection: network check, one-paste server install, live
  checks that turn green on their own, cloud firewall step, connection test.
- Local proxy: SOCKS5 127.0.0.1:10808 and 10809, HTTP 127.0.0.1:10810. Optional password-protected phone sharing on
  port 10811 with a QR code.
- Connection test, a status overview on the dashboard, and a menu bar item.
- Servers: several profiles, change IP, new keys, health check, export and import.
- System proxy toggle, launch at login, update check.
